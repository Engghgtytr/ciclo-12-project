DEMONSTRAÇÃO: dados só neste navegador. Usuários e doações são fictícios.

Comida boa não é lixo: ela vai para quem precisa.

Mercados, padarias, restaurantes e famílias publicam o que sobrou. ONGs e bancos de alimentos aprovados reservam e buscam.

1,05 bilhão de toneladas de alimentos foram desperdiçadas no mundo em 2022, e 60% disso aconteceu dentro das casas. Fonte: PNUMA, Food Waste Index Report 2024.

Aviso Esta plataforma intermedeia contato. Alimentos perecíveis seguem regras sanitárias; confira validade e condições. Protótipo escolar.

Privacidade: que dados guardamos e por quê
  • Nome, organização e e-mail: para você entrar e para o admin saber quem é cada receptor.
  • Tipo de perfil (doador ou receptor) e se o receptor foi aprovado: para cada um ver só o que pode.
  • Doações: alimento, quantidade, validade, bairro e horário. O endereço de retirada fica escondido e só aparece para o receptor que reservou.
  • Não pedimos CPF, telefone nem documento.
  • As regras de quem vê o quê são aplicadas pelo próprio banco de dados (Row Level Security), não só pela tela.
  • Protótipo escolar: o próximo passo é escrever uma política de privacidade completa, seguindo a LGPD.
